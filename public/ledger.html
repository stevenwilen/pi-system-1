WHAT MAKES IT READ AS BUILT
Two typefaces, split by job. Every number is IBM Plex Mono with tabular figures, so times and durations align in real columns down the page. Every name is Inter. Nothing crosses over.
Real column headers. # / TIME / BLOCK / STATUS under a 1.5px rule. The index column is what makes it a table rather than a list.
Three rule weights, each meaning something. 1.5px solid ends a section. 1px hairline separates rows. 1px dashed marks a gap that isn't a row at all.
Free time is hatched. Diagonal 45° hatching, the drafting convention for an empty region, with its span measured beside it.
The active row is marked four ways. Blue bar in the gutter, tinted ground, heavier weight, and its index goes blue. No badge.
Blue acts, and only acts. The active marker, + block, + anytime, and the one figure that changes. Nothing decorative is blue.
